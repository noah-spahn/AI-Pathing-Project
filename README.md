# AI Pathfinding Platformer (Java)

## Overview
This project is a Java-based platformer game developed as part of a software engineering course. The main focus of the project is an AI-controlled character that navigates through a 2D environment filled with obstacles in order to reach a designated goal block.

The AI uses basic movement logic, including walking and jumping, to determine a viable path through the level.

---

## Team Project
This project was developed by a team of three students. The goal was to design and implement an AI system capable of navigating a platformer environment while handling obstacles and terrain changes.

---

## Gameplay / AI Behavior
- The player does not directly control the character
- An AI agent controls movement automatically through dijkstra algorithm
- The AI attempts to reach the end goal block
- The environment includes obstacles that require jumping and path adjustment
- The AI continuously evaluates movement options to progress toward the goal

---

## Features
- AI-driven character movement
- Basic pathfinding logic for navigating a 2D grid-based world
- Jumping and collision-aware movement system
- Obstacle avoidance and terrain traversal
- Goal detection system (end block completion condition)
- Real-time simulation of AI decision-making
